## 찾아서 고친 문제

영상 요소가 전체화면인 상태에서 상위 문서에 바로 전체화면을 요청하면, 이전 영상에도 전체화면 상태가 남았다. 채팅이 논리적으로 열려 있어도 영상이 화면 전체를 덮는 현상을 실제 브라우저에서 확인했다.

`landscape-chat.ts`에서 영상 전체화면을 먼저 종료한 뒤 방 전체화면을 요청하도록 수정했다. 수정 전에는 `:fullscreen` 요소가 HTML과 영상 두 개였고, 수정 후에는 HTML 하나만 남으며 영상·채팅의 경계가 나뉘는 것을 확인했다. 자동 검사에도 종료 → 방 전체화면 순서를 추가했다.

## 배포 전에 남은 절차

- 점검 기준 GitHub `main`은 `2ac7b13`이었다. 위 전체화면 최종 수정과 옛 로컬 실행 자료 정리를 이번 커밋에 포함한다. 배포 전에는 GitHub의 최종 커밋과 운영 서버의 코드를 따로 확인한다.
- 현재 서버는 이전 코드 `46ccd5d`이며 배포·재시작·selftest·실제 회원의 도름 전송은 하지 않았다.
- 실제 Android·iPhone의 터치감·회전·전체화면과 실제 도름스 시험 계정의 최초 동의·전송은 추가 확인이 필요하다. 브라우저 크기 시험과 가짜 도름스 검사를 실제 기기·실제 회원 시험으로 보고하지 않는다.
- Windows에서 Linux 설치·재부팅 전체 시험은 하지 않았다. 이번 서버 점검은 운영 상태를 읽은 결과다.
- 배포는 참여 상태를 다시 확인하고 최신 백업을 만든 뒤 기존 `sudo dolivectl update` 절차로 진행한다. 서버 비밀 설정·목록·모델·인증서를 로컬 설정으로 덮어쓰지 않는다.
