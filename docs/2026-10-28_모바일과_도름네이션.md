# 모바일 가로 화면과 도름네이션 로그인 변경

## 변경 내용

- 휴대폰 가로에서는 영상이 왼쪽, 참여자·조작 버튼과 채팅이 오른쪽에 보인다. 화면공유 중에도 같은 배치다. PC와 휴대폰 세로 배치는 유지한다.
- 오른쪽 X는 퇴장이 아니라 채팅 숨기기다. 영상·통화·채팅 연결을 끊거나 컴포넌트를 새로 만들지 않는다.
- 영상만 보는 동안 화면을 한 번 누르면 오른쪽 위에 겹친 말풍선 아이콘이 2.5초 동안 나타난다. 누르면 오른쪽 채팅이 열린다. 영상 요소만 브라우저 전체화면이었다면 방 전체화면으로 바꿔 채팅도 표시한다.
- 가로 화면 경계를 손가락으로 끌어 채팅 너비를 조절한다. 터치 범위는 20px이며 페이지 스크롤과 충돌하지 않게 한다. 드래그 중에는 CSS 너비만 갱신하고 방 전체를 React로 반복해서 그리지 않는다. 잡은 위치부터 이동량을 계산해 처음 끌 때 너비가 튀지 않게 한다. PC에서 기억한 너비와 휴대폰 너비는 분리한다.
- 도름스 0.5.0의 로그인 동시 허용 방식을 합쳤다. 전송 권한이 없거나 만료돼도 도름네이션 때문에 방송 페이지가 자동 이동하지 않는다. 필요한 회원은 직접 새 창에서 확인하고 원래 화면에서 권한을 다시 확인한다.
- 받는 사람 확인, 1~3도름 제한, 도름스의 잔액·하루 한도 판정, 같은 요청 번호 재시도와 성공 뒤 방송 효과는 유지한다.

## 확인과 남은 일

- GitHub와 운영 서버의 기준 코드는 `46ccd5d`였다. 원래 로컬 폴더에서 먼저 `git pull --ff-only origin main`을 실행해 같은 최신값임을 확인했다.
- 운영 서버는 상태와 등록 정보만 읽었다. 서비스 재시작, 배포, 운영 회원의 실제 전송 시험은 하지 않았다.
- 도름스 `detect`로 Next.js 16 App Router 지원, `doctor`로 운영 주소 등록과 도름네이션 승인을 확인했다. 참고본을 검토해 기존의 Caddy 바깥 주소 처리와 방송 수신자 검사를 보존했다.
- `npm --prefix apps/web test`의 16개 시험과 `npm --prefix apps/web run build`를 통과했다. 도름네이션은 격리된 가짜 도름스·서명·시험 잔액으로 로그인·허용·전송·중복·오류·철회·로그아웃을 확인했다.
- 로컬 브라우저에서 채팅 숨김 → 영상 누르기 → 아이콘 → 채팅 복원, 경계 드래그를 확인했다. 실제 휴대폰의 터치감, 기기 회전·전체화면, 실제 도름스 시험 계정으로 처음 동의와 전송은 배포 전 추가 확인이 필요하다.
- GitHub 코드 변경과 운영 서버 반영은 별개다. 이번 작업은 GitHub 푸시까지이며 실제 배포는 따로 진행한다.
